À propos

Merise Studio est un site éducatif pour dessiner les modèles de la méthode MERISE sans installer de logiciel lourd.

Objectif

Permettre à un étudiant ou un enseignant de construire un MCD ou un MLD, de le relier, de le styliser, de l’enregistrer sur un compte, et d’en extraire une image ou un script SQL de départ.

Technique

Le site est en HTML, CSS et JavaScript (aucun framework). Les comptes et les diagrammes passent par une API PHP et une base MySQL. Le canevas est du SVG natif.

Limites

Le SQL généré est une aide pédagogique : il faut le relire avant de l’utiliser en production. Les exports PDF s’appuient sur la boîte d’impression du navigateur.
