Mentions légales

Merise Studio est un projet éducatif. L’éditeur du site est la personne ou l’établissement qui l’héberge (voir api/config.php côté serveur).

Hébergement

Le site s’exécute sur le serveur PHP/MySQL que vous avez configuré (machine locale de type XAMPP/WAMP, ou hébergeur).

Propriété intellectuelle

Les diagrammes que vous créez vous appartiennent. Le code de l’application est fourni pour un usage pédagogique.

Responsabilité

Les exports et le SQL généré sont des aides. Vérifiez vos modèles avant tout usage réel. Le service peut être interrompu sans préavis sur une installation locale.
